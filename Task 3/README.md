🎬 AI Movie Recommendation System

DecodeLabs Artificial Intelligence Internship — Task 3

This project is an AI-based Movie Recommendation System that recommends movies based on the user's preferred genres. It uses a content-based recommendation approach to compare user-selected genres with movie genres and rank movies according to their matching score.

🚀 Features

- 🎭 Select one or multiple movie genres
- 🤖 Calculate movie similarity using genre matching
- ⭐ Rank movies based on Match Score
- 🎬 Display personalized movie recommendations
- 🖥️ Interactive Tkinter GUI
- 🔄 Clear selections and try different preferences
- ⚠️ Input validation when no genre is selected

🧠 How It Works

1. The user selects their preferred movie genres.
2. The system compares the selected genres with each movie's genres.
3. A Match Score is calculated based on the number of matching genres.
4. Movies with at least one matching genre are selected.
5. The recommendations are sorted from the highest to the lowest score.
6. The ranked recommendations are displayed through the GUI.

Example

If the user selects:

Action + Sci-Fi

Movies containing both genres receive a higher Match Score than movies containing only one matching genre.
