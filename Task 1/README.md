# DecodeLabs Task 1 – AI Chatbot

## 📌 Project Overview

This project was developed as part of my **DecodeLabs Internship – Task 1**.

The objective of this task was to develop an interactive **AI Chatbot** that can accept questions from users and provide appropriate responses through a user-friendly graphical interface.

Instead of displaying the conversation only in the terminal, the chatbot provides a dedicated application window where users can interact with it.

---

## 🎯 Objective

The main objective of this project is to build a simple and interactive chatbot application that demonstrates the use of:

- Artificial Intelligence concepts
- Natural Language Processing
- Python programming
- Graphical User Interface development
- User input and response handling

---

## ✨ Features

- 🗨️ Interactive chatbot conversation
- 🖥️ Dedicated graphical user interface
- ⌨️ User input through a text box
- 🤖 Automated chatbot responses
- 📜 Displays conversation history
- 🔄 Supports continuous conversations
- ❌ Simple and easy-to-use interface
- ⚠️ Handles unknown or unsupported questions gracefully

---

## 🛠️ Technologies Used

### Python

Python is used as the primary programming language for developing the chatbot and handling its application logic.

### Tkinter

Tkinter is used to create the graphical user interface of the chatbot.

It provides components such as:

- Window
- Text area
- Input field
- Buttons
- Labels

### Artificial Intelligence

AI concepts are used to process user questions and generate appropriate chatbot responses.

### Natural Language Processing

Natural Language Processing concepts are used to understand and handle user queries.

💬 How the Chatbot Works

The chatbot follows a simple interaction process:

User enters a question
        ↓
Chatbot receives the input
        ↓
Input is processed
        ↓
Chatbot determines an appropriate response
        ↓
Response is displayed in the GUI
        ↓
User continues the conversation


---

🖥️ User Interface

The application provides a dedicated window where:

1. The conversation is displayed.


2. The user enters a question.


3. The chatbot processes the question.


4. The response is displayed in the conversation area.


5. The user can continue asking questions.
